sandbox-server에서 Oracle 19c 설치를 계속해줘. 서버 별칭은 반드시 "sandbox-server" 를 사용해. sandbox 유저의 sudo 패스워드는 Welcome1!@#$ 이야. 모든 파일은 이미 sandbox-server의 /tmp/에 있어: LINUX.X64_193000_db_home.zip, db_install_custom.rsp, oracle-database-preinstall-19c-1.0-1.el9.x86_64.rpm (이 이름 그대로), p37960098_190000_Linux-x86-64.zip, p6880880_190000_Linux-x86-64.zip. 지금 해야 할 작업을 bash 도구로 직접 실행해: (1) bash 도구로 server="sandbox-server" 설정하고 sudo rpm -ivh /tmp/oracle-database-preinstall-19c-1.0-1.el9.x86_64.rpm 실행 (root_password="Welcome1!@#$"). (2) getent passwd oracle 확인. (3) sudo mkdir -p /u01/app/oracle/product/19.0.0/dbhome_1 && sudo chown -R oracle:oinstall /u01/app/ && sudo chmod 755 /u01 /u01/app /u01/app/oracle. (4) sudo -u oracle unzip -q /tmp/LINUX.X64_193000_db_home.zip -d /u01/app/oracle/product/19.0.0/dbhome_1/. (5) sudo -u oracle bash -c "rm -rf /u01/app/oracle/product/19.0.0/dbhome_1/OPatch && unzip -q /tmp/p6880880_190000_Linux-x86-64.zip -d /u01/app/oracle/product/19.0.0/dbhome_1/". (6) sudo -u oracle bash -c "mkdir -p /tmp/patches && unzip -q /tmp/p37960098_190000_Linux-x86-64.zip -d /tmp/patches/". (7) sudo -u oracle bash -c "ORACLE_BASE=/u01/app/oracle /u01/app/oracle/product/19.0.0/dbhome_1/runInstaller -silent -ignorePrereqFailure -responseFile /tmp/db_install_custom.rsp -applyRU /tmp/patches/37960098 -waitforcompletion". (8) sudo /u01/app/oracle/product/19.0.0/dbhome_1/root.sh. 각 단계 결과를 확인하면서 진행하고, 오류가 발생하면 즉시 해결해줘.
