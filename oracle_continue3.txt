sandbox-server에서 Oracle 19c 설치를 진행해줘. 모든 sudo 명령은 반드시 "echo 'Welcome1!@#$' | sudo -S" 형식으로 실행해야 해. 파일들은 /tmp/에 이미 있어. bash 도구에 server="sandbox-server" 설정하고 순서대로 실행해: (1) echo 'Welcome1!@#$' | sudo -S rpm -ivh /tmp/oracle-database-preinstall-19c-1.0-1.el9.x86_64.rpm. (2) getent passwd oracle. (3) echo 'Welcome1!@#$' | sudo -S mkdir -p /u01/app/oracle/product/19.0.0/dbhome_1 && echo 'Welcome1!@#$' | sudo -S chown -R oracle:oinstall /u01/app/ && echo 'Welcome1!@#$' | sudo -S chmod 755 /u01 /u01/app /u01/app/oracle. (4) echo 'Welcome1!@#$' | sudo -S -u oracle unzip -q /tmp/LINUX.X64_193000_db_home.zip -d /u01/app/oracle/product/19.0.0/dbhome_1/ (이 명령은 오래 걸릴 수 있음). (5) echo 'Welcome1!@#$' | sudo -S -u oracle bash -c "rm -rf /u01/app/oracle/product/19.0.0/dbhome_1/OPatch && unzip -q /tmp/p6880880_190000_Linux-x86-64.zip -d /u01/app/oracle/product/19.0.0/dbhome_1/". (6) echo 'Welcome1!@#$' | sudo -S -u oracle bash -c "mkdir -p /tmp/patches && unzip -q /tmp/p37960098_190000_Linux-x86-64.zip -d /tmp/patches/". (7) cat /tmp/db_install_custom.rsp. (8) echo 'Welcome1!@#$' | sudo -S -u oracle bash -c "export ORACLE_BASE=/u01/app/oracle; /u01/app/oracle/product/19.0.0/dbhome_1/runInstaller -silent -ignorePrereqFailure -responseFile /tmp/db_install_custom.rsp -applyRU /tmp/patches/37960098 -waitforcompletion" (이 명령은 30분 이상 걸릴 수 있음, background=true 로 실행). (9) 완료 후 echo 'Welcome1!@#$' | sudo -S /u01/app/oracle/product/19.0.0/dbhome_1/root.sh. 각 단계 성공/실패 확인하며 진행해.
