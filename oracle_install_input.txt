sandbox-server(192.168.0.130)에 Oracle 19c를 설치해줘. sandbox 유저 sudo 패스워드는 Welcome1!@#$ 이야. 설치 단계는 다음과 같아: (1) 로컬 파일 C:/Users/jhkwa/Downloads/oracle-database-preinstall-19c-1.0-1.el9.x86_64.rpm을 sandbox-server의 /tmp/로 server_copy로 복사하고, sudo rpm -ivh로 설치해. (2) 로컬 파일 C:/Users/jhkwa/Downloads/LINUX.X64_193000_db_home.zip을 sandbox-server의 /tmp/로 복사해. (3) 로컬 파일 C:/Users/jhkwa/Downloads/p6880880_190000_Linux-x86-64.zip (OPatch)을 /tmp/로 복사해. (4) 로컬 파일 C:/Users/jhkwa/Downloads/p37960098_190000_Linux-x86-64.zip (RU 패치)을 /tmp/로 복사해. (5) 로컬 파일 C:/Users/jhkwa/Downloads/db_install_custom.rsp를 /tmp/로 복사해. (6) oracle 계정 홈 확인: getent passwd oracle. (7) ORACLE_HOME=/u01/app/oracle/product/19.0.0/dbhome_1 디렉토리 생성(oracle 소유). (8) /tmp/LINUX.X64_193000_db_home.zip을 ORACLE_HOME에 unzip (oracle 계정으로). (9) OPatch: ORACLE_HOME/OPatch 디렉토리 삭제 후 /tmp/p6880880_190000_Linux-x86-64.zip 을 ORACLE_HOME에 unzip. (10) RU 패치: /tmp/p37960098_190000_Linux-x86-64.zip을 /tmp/patches/에 unzip. (11) oracle 계정으로 ORACLE_HOME/runInstaller -silent -ignorePrereqFailure -responseFile /tmp/db_install_custom.rsp -applyRU /tmp/patches/37960098 실행. (12) root.sh 실행. 모든 작업은 bash 또는 server_copy 도구로 직접 실행해. 문제가 생기면 오류를 보고하고 해결해.
