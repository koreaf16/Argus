sandbox-server에서 Oracle 19c 설치를 계속해줘. 모든 파일은 이미 /tmp/에 있어. sandbox 유저의 sudo 패스워드는 Welcome1!@#$ 이야. 지금 해야 할 작업: (1) sudo rpm -ivh /tmp/oracle-database-preinstall-19c-1.0-1.el9.x86_64.rpm 을 실행해서 oracle 계정과 그룹을 생성해. root_password는 Welcome1!@#$ 이야. (2) oracle 계정이 생성되었는지 확인: getent passwd oracle. (3) ORACLE_HOME 디렉토리 생성: sudo mkdir -p /u01/app/oracle/product/19.0.0/dbhome_1 && sudo chown -R oracle:oinstall /u01/app/ && sudo chmod -R 755 /u01/. (4) oracle 계정으로 LINUX.X64_193000_db_home.zip unzip: sudo -u oracle bash -c 'unzip -q /tmp/LINUX.X64_193000_db_home.zip -d /u01/app/oracle/product/19.0.0/dbhome_1/'. (5) OPatch 교체: sudo -u oracle bash -c 'rm -rf /u01/app/oracle/product/19.0.0/dbhome_1/OPatch && unzip -q /tmp/p6880880_190000_Linux-x86-64.zip -d /u01/app/oracle/product/19.0.0/dbhome_1/'. (6) RU 패치 unzip: sudo -u oracle bash -c 'mkdir -p /tmp/patches && unzip -q /tmp/p37960098_190000_Linux-x86-64.zip -d /tmp/patches/'. (7) db_install_custom.rsp 확인: cat /tmp/db_install_custom.rsp. (8) oracle 계정으로 silent 설치 실행: sudo -u oracle bash -c 'ORACLE_BASE=/u01/app/oracle /u01/app/oracle/product/19.0.0/dbhome_1/runInstaller -silent -ignorePrereqFailure -responseFile /tmp/db_install_custom.rsp -applyRU /tmp/patches/37960098 -waitforcompletion'. (9) root.sh 실행: sudo /u01/app/oracle/product/19.0.0/dbhome_1/root.sh. 각 단계를 bash 도구로 직접 실행하고, 오류가 있으면 즉시 해결해줘.
